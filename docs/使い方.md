# 試合分析ツールの使い方

ツールの場所：https://hiroki42977-prog.github.io/match-analysis-tool/

---

## 最初に1回だけ

### 1. iPad のホーム画面に追加する

iPad の Safari は、7日間開かなかったサイトのデータを消すことがあります。ホーム画面に追加して使えば、記録が消されません。

1. iPad の **Safari** で、上の「ツールの場所」の URL を開く
2. 画面右上の **共有ボタン（四角から上向きの矢印が出ているマーク）** をタップ
3. **「ホーム画面に追加」** をタップ → 右上の **「追加」**
4. 以後は、ホーム画面の **緑のピッチのアイコン「試合分析」** から開く
   （Safari から開くと、ホーム画面のものとは別の場所に保存されるので、記録が見えません。必ずアイコンから開いてください）

### 2. 受け取り係（Apps Script）を設置する

`/Users/tsurumaruhiroyuki/Desktop/分析スタッツツール/apps-script/設置手順.md` の手順どおりに行います。最後に、ツールの「設定」に URL と合言葉を入れます。

### 3. 名簿を登録する

1. ホームの **「名簿」** をタップ
2. **「チーム名」** に入力して **「チームを追加」**
3. **「背番号」** と **「名前」** を入れて **「選手を追加」**（全員分くり返す）

## 試合ごと

### 4. 試合を登録する

1. ホームの **「＋ 新しい試合」**
2. 日付・対戦相手・11人制／8人制・YouTube のリンク（メールで届いたもの）を入れる
3. 出場選手のチェックを確認して **「保存」**

### 5. 記録する（1人の選手を追う）

1. 試合を開いて、追う選手をタップ
2. 映像の **▶** をタップして再生
3. プレーが起きたら、次の順にタップ
   - パス・ドリブル：**プレー → 始点のマス → 終点のマス**
   - 守備：**プレー → 場所のマス**
   - シュート：**枠内R などのボタン → 打った場所のマス**
   - 失敗したときだけ、マスを押す前に **「失敗」** をタップ
4. 間違えたら：左の「直前の記録」の **「取消」**。パスの向き（前・横・後ろ）は、その横のボタンで直せます
5. 後半になったら **「後半」** をタップ
6. 別の選手を追うときは **「選手を変える」**。前に追った選手は、続きの場面から再生されます

左下に **「送信済み」** と出ていれば、スプレッドシートの「試合分析 記録一覧」にも保存されています。「未送信 ◯件」は、電波がつながると自動で送られます。

### 6. レポートを作る

1. 記録画面の **「結果を見る」**
2. 右上の **「レポート作成」** をタップ
3. 「◯人分のレポートを作りました」と出たら完了です。Google ドライブの「試合分析」フォルダに、選手ごとのファイル（例：「#10 山田 太郎（チーム名）」）ができます。試合ごとに「スタッツ」と「マップ」のタブが増えていきます

### 7. 選手に共有する（選手ごとに最初の1回だけ）

1. パソコンで Google ドライブの「試合分析」フォルダを開き、選手のファイルを開く
2. 右上の **「共有」** → 選手（または保護者）のメールアドレスを入力
3. 右の権限を **「閲覧者」** にして **「送信」**

2試合目からは、同じファイルにタブが増えるだけなので、共有し直す必要はありません。

## 困ったとき

| こんなとき | すること |
| --- | --- |
| 「送信先が未設定」と出る | ホームの「設定」で、URL と合言葉を入れて「保存」 |
| 「未送信」がずっと減らない | 「設定」の「送信テスト」を押し、出てきたメッセージを Claude に伝える |
| 記録が消えた気がする | ホーム画面のアイコンから開いているか確認する（Safari から開くと別の保存場所になる） |
| CSV がほしい | 「結果を見る」の「CSV 書き出し」。iPad の「ファイル」アプリに保存されます |
