# スプレッドシート出力を手書きの設計図の形にする 設計書

作成日：2026-10-22
参考：フォルダ直下の手書きの設計図 IMG_1487.JPG（1ページ目）・IMG_1488.JPG（2ページ目）。git には入れない。

## 目的

選手に渡す正式な資料を Google スプレッドシートにする。PDF が要るときはスプレッドシートから書き出す。
ツールが数えた数字・図はツールが入れ、ひろきさん以外の担当者が書く欄は空けておき、そのままスプレッドシートに書き込めるようにする。

## ひろきさんが決めたこと

- 出力はスプレッドシートを正とする。PDF はスプレッドシートから書き出す。ツールの PDF ボタンは今回は触らない（残す）。
- ファイルは今と同じく選手ごとに1ファイル。
- 1ページ目のレーダーチャートより上（写真・〇 vs 〇・スコア・名前などの項目・ポジション図）と、2ページ目のコメント・次節の課題は、ひろきさんが埋める場所ではない。ツールは枠と項目名だけ作って空けておく。
- 表の中身は、これまでツールで数えていたものと同じ。
- ロゴは入れない。設計図の右上の丸の文字も入れない。
- 枠も表もツールが毎回組み立てる（ひな形のスプレッドシートは使わない）。

## タブの形

- 試合ごとに1タブ。名前は「M/D vs 相手」（例：`10/19 vs ◯◯`）。
- 前の版で作った「◯◯ スタッツ」「◯◯ マップ」のタブは消さずに残す。新しいファイルを作ったときだけ、最初からある空のシートを消す（今と同じ）。
- 1タブの中に、1ページ目・2ページ目を縦に並べる。列幅と行の高さは、A4縦・「幅に合わせる」で書き出したとき、1ページ目の終わりで2ページ目に切り替わる大きさにそろえる。

## 1ページ目（上から）

1. 見出しの段：「写真」の枠｜「〇 vs 〇」の枠（左右に空欄、真ん中に vs）｜スコアの枠（項目名「スコア」「1st」「2nd」「Total」と、その横に空欄）
2. 項目の段（左）：名前、映像LINK、評価1st、評価2nd、出場ポジ、個人テーマ（攻）、個人テーマ（守）、分析官、アシスト・ゴール。項目名の右は空欄
3. 項目の段（右）：試合条件、試合時間、出場時間、KO時間、天候、ピッチコンディション、フィジカル、メンタル、システム。項目名の右は空欄
4. ポジション図の枠：見出しの段と項目の段の右側にまたがる大きな空欄（担当者が選手の位置を描くか、図を貼る）
5. レーダーチャート3つを横に並べる：前半｜後半｜全体。ツールが入れる（画像）
   - 全体は、前半と後半の回数を足してから成功率を出す
6. 表：パス成功率／ドリブル成功率／守備成功率／シュート成功率。ツールが入れる
   - 中身はこれまでの表と同じ（各項目の成功・失敗・総数を前半・後半で、最後に成功率）

## 2ページ目（上から）

1. 「プレーマップ 1st」の見出しと図（今の 1st の図と同じ）。ツールが入れる
2. 凡例（パス・コンドゥクシオン・レガテなど、今の凡例と同じ絵）。ツールが入れる
3. 「プレーマップ 2nd」の見出しと図。ツールが入れる
4. 「コメント」の見出しと、広い空欄
5. 「次節の課題」の見出しと、「攻」「守」それぞれの広い空欄

## 空けておく欄

- セルをつなげて広めの書き込み欄にし、細い罫線で囲む。
- 文字は折り返して表示し、上詰めにする。

## 送り直したときに書き込みを消さない

- その試合のタブがまだ無いとき：タブを作り、枠・項目名・ツールの中身を全部入れる。
- その試合のタブがもうあるとき：タブは作り直さない。ツールが入れる場所（レーダー・表・プレーマップ・凡例）だけを書き換える。
  - ツールが貼った画像には目印（代替テキストのタイトル）を付けておき、その目印の画像だけ消して貼り直す。
  - 担当者が書いた文字・貼った写真や図はそのまま残る。

## 変えるところ

- アプリ側（src/report/）
  - 送る中身を、新しいタブの形に合わせて作り直す（タブ名1つ、レーダー3枚、表、プレーマップ2枚、凡例）。
  - レーダー図を「全体」でも描けるようにする。
- Apps Script 側（apps-script/Code.gs）
  - 新しいタブを組み立てる処理と、既にあるタブのツールの場所だけ書き換える処理を足す。
  - 動作確認用の selfTest を新しい形に合わせる。
  - 設置手順.md に、貼り替えの手順と PDF の書き出し方（ファイル → ダウンロード → PDF → 用紙 A4・縦・幅に合わせる）を書く。

## 確かめること

- アプリ側の自動テスト：送る中身（タブ名・表の数字・全体のレーダーの値・画像の数）が正しいこと。
- Apps Script 側：Google の外では動かせないので、組み立てのうち「どのセルに何を書くか」の計算は、テストできる形に分けて確かめる。
- ひろきさんに、Apps Script の貼り替え → selfTest の実行 → iPad から送信、をしてもらい、次を見てもらう。
  - 手書きの設計図と見比べて形が合っているか
  - PDF に書き出して A4縦2枚にきれいに分かれるか
  - 空けておく欄に文字を入れてから送り直し、文字が残るか
- それまでは「実機では未確認」とする。

## 気をつけること

- Apps Script には改ページの位置を決める機能が無い。列幅・行の高さで1ページ目の大きさを合わせるが、ずれた場合は、書き出しの画面で改ページの位置を動かす方法を案内する。
- Apps Script を書き換えたら、ひろきさんに貼り替えてもらうまで、新しい形は出ない。アプリだけ先に新しくすると、古い受け取り係では新しい中身を受け取れないので、アプリが送る中身に版を付け、古い受け取り係なら「受け取り係の貼り替えが必要です」と分かるエラーを出す。
