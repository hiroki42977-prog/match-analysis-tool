# 受け取り係（Apps Script）の設置手順

iPad のツールから送った記録を、Google スプレッドシートに書き込む「受け取り係」を、ひろきさんの Google アカウントに設置する手順です。最初に1回だけ行います（10分ほど）。

Mac のブラウザ（Chrome か Safari）で、普段使っている Google アカウントにログインした状態で始めてください。

---

## 1. 合言葉を決める

ツールとこの受け取り係だけが知っている「合言葉」を決めます。ほかの人が勝手に書き込めないようにするためのものです。

- 英字と数字をまぜた **20文字くらい** にしてください（例の形：`k7Qm2xR9pLw4Tz8vNb3s`。この例はそのまま使わないでください）。
- 合言葉は、メモアプリなどに控えておいてください。このあと2か所（手順4と手順7）に入力します。
- 合言葉は、チャットやメール、SNS に書かないでください。

## 2. 新しいプロジェクトを作る

1. https://script.google.com を開く
2. 左上の **「新しいプロジェクト」** をクリック
3. 左上の **「無題のプロジェクト」** をクリックし、名前を `試合分析 受け取り係` にして **「名前を変更」**

## 3. プログラムを貼り付ける

1. 画面の中央に `function myFunction() {` から始まる文字があります。ここを全部消します（クリックしてから `command + A` → `delete`）
2. Mac のファインダーで、次のファイルをテキストエディットで開きます
   `/Users/tsurumaruhiroyuki/Desktop/分析スタッツツール/apps-script/Code.gs`
3. 中身を全部コピーして（`command + A` → `command + C`）、ブラウザの中央に貼り付けます（`command + V`）
4. 上の **フロッピーディスクの形のボタン（プロジェクトを保存）** をクリック

## 4. 合言葉を登録する

1. 左端の **歯車のマーク（プロジェクトの設定）** をクリック
2. いちばん下の **「スクリプト プロパティを追加」** をクリック
3. **「プロパティ」** に `TOKEN`（半角の大文字）、**「値」** に手順1の合言葉を入力
4. **「スクリプト プロパティを保存」** をクリック

## 5. 動作確認と、許可をする

1. 左端の **`< >` のマーク（エディタ）** をクリックして、手順3の画面に戻る
2. 上の **「実行」** の右にある、関数を選ぶ欄（`doGet` などと書いてある）をクリックし、**`selfTest`** を選ぶ
3. **「実行」** をクリック
4. 「承認が必要です」と出たら **「権限を確認」** → 自分の Google アカウントを選ぶ
5. 「Google はこのアプリを検証していません」と出たら、左下の **「詳細」** → **「試合分析 受け取り係（安全ではないページ）に移動」** をクリック
   （自分で作ったプログラムなので、この表示が出るのが普通です）
6. **「許可」**（または「続行」）をクリック
7. 画面の下の「実行ログ」に `OK:` で始まる行が出たら成功です
8. Google ドライブ（https://drive.google.com）を開き、**「試合分析」** フォルダの中に **「#0 動作確認（テスト）」** と **「試合分析 記録一覧」** ができているか確認します
   - 「#0 動作確認（テスト）」を開いて、画面の左下に **「動作確認」** という名前のタブができているか見てください。できていなければ、そのことを Claude に伝えてください
   - 確認が済んだら「#0 動作確認（テスト）」は消してかまいません

## 6. ウェブアプリとして公開する

1. 右上の青い **「デプロイ」** → **「新しいデプロイ」** をクリック
2. 左の **「種類の選択」** の横にある **歯車のマーク** → **「ウェブアプリ」** をクリック
3. 次のように設定します
   - 説明：`試合分析`
   - 次のユーザーとして実行：**「自分」**
   - アクセスできるユーザー：**「全員」**
4. **「デプロイ」** をクリック
5. **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/` で始まるもの）の右の **「コピー」** をクリックし、メモアプリに貼っておきます
6. **「完了」** をクリック

「アクセスできるユーザー：全員」にしても、合言葉を知らない人は書き込めません。URL と合言葉は、ほかの人に教えないでください。

## 7. ツールに入力する

1. ツールを開き、ホームの右上の **「設定」** を押す
2. **「Apps Script の URL」** に手順6でコピーした URL、**「合言葉」** に手順1の合言葉を入力
3. **「保存」** を押す
4. **「送信テスト」** を押して、**「つながりました」** と出れば設置は完了です

## 受け取り係を新しくする

Claude から「受け取り係を新しくしてください」と頼まれたときや、ツールに「受け取り係を新しくしてください」と出たときに行います。**合言葉も URL も変わりません**（合言葉と URL は、チャットやメールに書かないでください）。

1. https://script.google.com を開き、**「試合分析 受け取り係」** をクリック
2. 画面の中央をクリックし、`command + A` → `delete` で、中の文字を全部消す
3. Mac のファインダーで、次のファイルをテキストエディットで開く
   `/Users/tsurumaruhiroyuki/Desktop/分析スタッツツール/apps-script/Code.gs`
4. 中身を全部コピーして（`command + A` → `command + C`）、ブラウザの中央に貼り付ける（`command + V`）
5. 上の **フロッピーディスクの形のボタン（プロジェクトを保存）** をクリック
6. 上の関数を選ぶ欄で **`selfTest`** を選び、**「実行」** をクリック。画面の下の「実行ログ」に `OK:` で始まる行が出れば成功です（`NG:` で始まる行が出たら、その行を Claude に伝えてください）
7. 右上の **「デプロイ」** → **「デプロイを管理」** をクリック
8. 右上の **鉛筆のマーク（編集）** をクリック → **「バージョン」** を **「新バージョン」** にする → **「デプロイ」** をクリック

この方法なら URL は変わらないので、ツールの設定はそのままで使えます。

## PDF の書き出し方

選手のスプレッドシートを PDF にして、印刷したり送ったりするときの手順です。

1. パソコンで、選手のスプレッドシートを開き、書き出したい試合のタブをクリック
2. 左上の **「ファイル」** → **「ダウンロード」** → **「PDF」** をクリック
3. 右に出る設定を、次のようにする
   - 用紙サイズ：**「A4」**
   - ページの向き：**「縦向き」**
   - スケール：**「幅に合わせる」**
   - 余白：**「標準」**
4. **「エクスポート」** をクリック

余白を「標準」以外に変えると、3ページになることがあります。
